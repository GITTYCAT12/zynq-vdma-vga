# Zynq-7000 Real-Time Video Interfacing using AXI VDMA

A hardware/software video pipeline for the Zynq-7000 SoC using AXI VDMA, DDR frame buffering, VTC, AXI4-Stream video output, and standalone ARM software.

## Highlights

- **Zynq-7000 / XC7Z020CLG400-1** target.
- **100 MHz PL/AXI clocking** from PS `FCLK_CLK0`.
- **AXI VDMA MM2S** for hardware-managed DDR-to-video streaming.
- **24-bit RGB, 640×480 framebuffer** with a 1920-byte line stride.
- **Cache flush before DMA** so VDMA reads current framebuffer data from DDR.
- **Circular VDMA mode** for continuous frame reuse with minimal CPU intervention.
- **HP0 DDR path + SmartConnect** for the high-performance memory data path.
- **VTC + AXI4-Stream video output** for timing and video transport.
- Standalone **ARM Cortex-A9** software initializes the framebuffer and DMA engine.

## Software startup sequence

The standalone application follows a deliberate order so the DMA engine is never started against an invalid framebuffer configuration:

1. Validate the frame dimensions and stride.
2. Generate the 640×480 RGB color-bar pattern in DDR.
3. Flush the CPU data cache for the complete framebuffer range.
4. Initialize the AXI VDMA MM2S channel.
5. Program the framebuffer address, line size, stride, and circular-buffer mode.
6. Start VDMA and leave frame streaming to hardware.

The application also checks VDMA configuration, driver initialization, DMA configuration, buffer-address programming, and DMA start status. Any failure stops initialization and reports the failing stage over UART.

## Framebuffer configuration

The current software configuration is:

| Parameter | Value |
|---|---:|
| Resolution | 640 × 480 |
| Pixel format | 24-bit RGB |
| Bytes per pixel | 3 |
| Line stride | 1920 bytes |
| Framebuffer base | `0x10000000` |
| VDMA direction | MM2S (DDR → stream) |
| Buffer mode | Circular |

The framebuffer base is kept word-aligned, and the software verifies that the supplied stride is large enough for the selected RGB width. The color-bar generator also requires the width to divide evenly into eight bars.
